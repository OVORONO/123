Проект #2

Family Tree

Сервис по созданию генеологических деревьев

Я разработал сайт Family Tree как платформу для создания семейного генеалогического древа.

Пользователи находят предков через поиск по архивам, строят ветви рода, делятся историями и фото.

Система уведомлений, экспорт в PDF и мощная база данных демонстрируют мои профессиональные навыки в full-stack разработке.

Описание проекта

Сервис предоставляющий возможности создания и редактирования собственного генеалогического древа, что очень полезно в условиях современного общества.
